open-source usage trackers, with identity fields removed. They cover plan
shapes no maintainer account can reproduce (Pro, Pro Lite, blocked accounts).

| Fixture | Origin |
|---------|--------|
| `codex-pro-blocked.json` | `OpenAgentsInc/openagents` usage fixture |
| `codex-prolite-spark.json`, `codex-plus-string-balance.json`, `codex-api-key-no-rate-limit.json`, `codex-pro-limit-reached-malformed-extra.json` | `AThevon/TokenEater` test fixtures |
| `codex-prolite-credits.json` | `niederme/ai-quota` API surface notes |
